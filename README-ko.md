# Edgetree v2.6.2

[English](README.md)

윈도우 화면 좌우에 상시 고정되는, VS Code 탐색기 방식의 가벼운 파일 탐색 유틸입니다.
기본 윈도우 탐색기를 대체하려는 목적이 아니라, 폴더 구조를 빠르게 훑어보고
파일 위치로 바로 이동하기 위한 보조 도구입니다.

## 다운로드

[릴리즈 페이지](https://github.com/legendsteel11/Edgetree/releases/latest)에서 최신 버전을 받으세요. 매 릴리즈마다 파일 3개가 첨부되어 있습니다.

- **`Edgetree-<버전>-win-x64-setup.exe`** (약 49MB) — 설치 버전. 몇 번 클릭하면 시작 메뉴에 등록되고, 제거도 깔끔합니다.
- **`Edgetree-<버전>-win-x64-standalone.exe`** (약 155MB) — 무설치. 파일 하나를 원하는 곳에 두고 바로 실행합니다.
- **`Edgetree-<버전>-win-x64.exe`** (약 1MB) — 경량. [.NET 8 데스크톱 런타임](https://dotnet.microsoft.com/download/dotnet/8.0)이 설치된 PC에서 쓰는 판입니다.

설정은 `%AppData%\Edgetree`에 있고 셋이 같이 씁니다. 어느 쪽으로 옮겨도 북마크·색상이 그대로 유지되고, 제거해도 남습니다.

## 주요 기능

- **화면 가장자리 고정 배치** — 기본은 좌측, 옵션 메뉴에서 우측으로도 전환
  가능 (작업표시줄을 제외한 작업영역 기준 전체 높이), 고정 상태에서는
  Alt+Tab/작업표시줄에서 제외됨
- **오토하이드**: 헤더의 핀 버튼 한 번으로 화면 가장자리에 얇은 바만 남기고
  완전히 숨겨짐 — 핀이 옆으로 누우면 자동 숨김 중이라는 표시이고, 다시
  누르면 핀이 세워지며 고정으로 돌아옴. 마우스를 가장자리로 가져가면
  자동으로 펼쳐지고, 기본값으로는 마우스가 벗어나면 다시 조용히
  숨겨짐(옵션 메뉴의 "마우스 이탈 시 닫기"를 비활성화하면 대신 바깥을 클릭해야 닫히는
  방식으로 전환 가능). 숨겨졌을 때 남는 얇은 바의 두께도 옵션 메뉴에서
  3~8px로 조절 가능. 가장자리 전체 대신 **화면 가운데의 짧은 손잡이만** 남기는
  것도 선택할 수 있고, 그때의 색도 따로 정할 수 있음
- **드래그로 폭 조절** (고정 상태에서), 우측 리사이즈 라인을 더블클릭하면
  현재 표시된 행 중 가장 긴 내용에 맞춰 폭이 자동으로 늘어나고, 다시
  더블클릭하면 그 전 폭으로 되돌아옴
- **자유 이동 창으로 분리**: 상단 헤더를 드래그하면 고정이 풀리면서
  자유롭게 이동/리사이즈 가능한 일반 창으로 전환(이때는 Alt+Tab/작업표시줄에도
  나타남). 헤더의 핀 버튼을 누르면 다시 가장자리에 고정되고 전체 높이로
  복원 — 고정/자유이동을 오갈 때마다 직전 창 위치와 크기를 기억함
- **드라이브 기반 루트("내 PC")**: 연결된 모든 드라이브를 최상위에 나열,
  폴더는 펼칠 때마다 하위 항목을 지연 로딩
- **이전 상태 그대로 복원**: 펼쳐뒀던 폴더들과 마지막으로 선택했던 위치가
  앱을 다시 실행해도 그대로 돌아옴
- **큰 폴더도 빠르게**: 폴더마다 처음 50개 항목만 표시하고 "… 더 보기 (N개)"
  줄로 나머지를 펼침 — 트리가 한 번에 수천 개 행을 그리지 않아, 파일이 아주
  많은 폴더 아래의 북마크로 이동해도 즉시 반응. 표시 개수는 옵션 메뉴에서
  1~50개로 조절 가능(저해상도 화면 고려)
- **파일 형식 필터**: 하단 바의 칩으로 코드·이미지·문서·미디어·압축·실행
  파일 중 트리에 보일 것을 선택하고 나머지는 트리에서 빠짐. 원하는 확장자를
  직접 지정하거나(사용자 지정), 항상 숨길 확장자를 따로 적을 수 있음(제외).
  검색은 필터로 걸러진 파일도 찾음
- **경로 표시줄**: 경로를 직접 입력해 바로 이동. `Ctrl+←` / `Ctrl+→` 또는
  마우스 앞·뒤 버튼으로 사용했던 폴더를 뒤로·앞으로 오가고, 표시줄에서 그
  목록을 볼 수 있음
- **네트워크 위치**: 드라이브 문자가 없는 공유 폴더(`\\서버\공유`)를 트리 빈 곳
  우클릭 메뉴에서 추가하면 트리에 계속 남음
- **설정 내보내기/가져오기**: 설정을 JSON 파일로 저장하고 다른 PC에서 불러오기
  (북마크 포함, 해당 PC에 없는 경로는 자동으로 정리됨)
- 폴더 행을 한 번 클릭하면 펼침/접힘 (VS Code처럼 화살표뿐 아니라 줄 전체 클릭
  가능), 파일은 더블클릭으로 기본 연결 프로그램 실행
- **멀티 셀렉트**: `Ctrl+클릭`으로 파일/폴더를 하나씩 추가·해제,
  `Shift+클릭`으로 화면에 보이는 순서 기준 범위 선택 — 선택한 항목들을 한
  번에 복사(`Ctrl+C`)·삭제(`Delete`, 확인창 1회)하거나 통째로 앱 밖으로
  드래그. 우클릭 메뉴 상단에 "N개 항목 선택됨"이 표시되고, 단일 대상
  동작(이름 바꾸기·경로 복사)은 자동으로 비활성화됨. `Esc` 또는 일반
  클릭으로 해제
- **폴더 자동 접기** (옵션 "..." 메뉴): 폴더 하나를 펼치면
  그 폴더까지 가는 경로만 남기고 나머지 열려있던 폴더는 자동으로 접힘
- **북마크 패널**: 헤더 아래에 폴더와 파일을 담아두고, 한 번 클릭하면 트리에서 해당
  경로까지 바로 펼쳐지고(대상 폴더 자신도 함께 펼쳐짐) 트리 맨 위에 오도록
  스크롤됨 — 파일이 아주 많은 폴더 아래에 있거나 다른 드라이브에 있어도 한 번의
  클릭으로 안정적으로 이동. 행마다 번호가 붙고 그 번호가 곧 Ctrl+Alt+L·J
  순환 순서이며, 행을 끌어서 순서를 바꿀 수 있음. 담긴 개수에 맞춰 높이가
  자동으로 맞춰지고(구분선 더블클릭으로 정확히 맞춤도 가능), 트리의 글자 크기
  확대/축소도 함께 따라감. 옵션 메뉴에서 탐색기 위/아래 위치 전환 가능(고정/창모드 모두 적용)
- **인라인 이름 바꾸기** (VS Code 방식): `F2` 또는 우클릭 메뉴로 트리 행에서
  바로 이름을 수정, 별도 팝업 없음. 이미 선택된 **파일**을 잠시 뒤 다시 한 번
  클릭해도 이름 바꾸기 시작(탐색기와 동일). 폴더는 클릭이 펼침/접힘이라 제외 —
  `F2`/우클릭 사용
- **북마크** (`Ctrl+Alt+K`): 자주 돌아오는 행에 표식을 달아두고
  `Ctrl+Alt+L` / `Ctrl+Alt+J`로 표시한 곳들을 순서대로 오갑니다. 표식은 행
  오른쪽 끝에 표시되고 앱을 다시 켜도 유지됨
- **폴더 숨기기**: 잘 안 쓰는 폴더나 드라이브를 우클릭 → "숨기기"로
  트리에서 감춰 둡니다. 여러 개를 선택한 뒤 한 번에 감출 수도 있습니다. 감춘 것은 바로 아래 "숨긴 폴더" 목록에 모여 있어
  하나씩 또는 한 번에 되돌릴 수 있고, 검색은 감춘 폴더 안도 그대로 찾습니다
  (검색 결과나 북마크로 그 안에 들어가면 그동안만 트리에 나타납니다)
- **압축 / 압축 풀기**: 우클릭 메뉴에서 선택 항목을 zip으로 묶고(여러 개면
  하나로), `.zip` 파일은 같은 이름의 폴더로 풀기
- **우클릭 메뉴**: 새 폴더, 새로고침, 열기, 연결 프로그램(파일 전용),
  복사/붙여넣기, 압축, 이름 바꾸기, 삭제(휴지통으로, 확인창 포함), 경로 복사,
  터미널에서 위치 열기, 탐색기에서 위치 열기(폴더는 그 폴더가 열리고, 파일은
  상위 폴더에서 선택됨), 속성 — 각각 단축키 지원
  (`F2`, `F5`, `F7`, `Delete`, `Ctrl+C`/`Ctrl+V`, `Enter`) — **이 우클릭 메뉴가
  열려 있는 동안에도 같은 단축키가 그대로 동작**(색상 설정 등 별도 팝업
  창이 열려 있을 때는 해당 없음); 메뉴가 대상 행을 가리지 않도록 항상 그
  아래에 열림
- **이미지 미리보기**: 이미지 파일을 우클릭하면 메뉴 상단에 썸네일과
  형식·픽셀 크기·용량·수정 날짜가 함께 표시됨 — 열지 않고 내용을 확인하고,
  썸네일을 클릭하면 바로 열림
- **파일을 앱 밖으로 드래그** — 탐색기나 다른 앱으로 끌어다 놓기(복사/이동/
  드롭하여 열기 모두 윈도우 표준 방식대로 동작)
- **멀티미디어 패널**: 제목 표시줄의 이미지 아이콘으로 트리 옆에 패널을 엶(좌우
  위치는 옵션에서 반전 가능). **더블클릭으로 열기**를 활성화하면 트리에서
  더블클릭한 파일이 기본 프로그램 대신 이 패널에서 열리고, 파일을 선택하면
  패널이 자동으로 열리는 옵션도 있음. `Backspace`로 패널을 축소하며, 재생
  볼륨은 저장되어 다음 실행에도 유지됨
- **그림 보기**: 휠로 확대·축소, `Ctrl`·`Shift`+휠로 정밀 조정, 확대 상태에서
  드래그로 이동(우측 하단에 내비게이터). 더블클릭으로 맞춤 ↔ 1:1 전환,
  채우기는 패널에 꽉 차게 잘라 보여줌. 일반 형식에 더해 PSD·RAW·JXL도 읽고,
  썸네일 바 크기를 따로 정할 수 있으며, 그림을 다른 앱으로 바로 끌어낼 수 있음.
  마우스 앞·뒤 버튼으로 이전·다음 그림으로 이동
- **슬라이드 쇼**: 이미지 우클릭 또는 `F8`
- **바탕 화면 배경 지정**: 모니터마다 다른 그림을 지정할 수 있음
- **음악은 백그라운드로 이어짐**: 패널을 닫아도 소리는 계속 남. 앨범아트가
  표시되고 `F9`로 패널 위에 시계를 띄울 수 있음
- **영상**: HDR 보정과 자막을 지원. 자막은 크기·위치·싱크를 조정할 수 있고
  (`<` `>`로 싱크 조정), 크기는 영상 크기에 연동되어 해상도와 창 크기에
  관계없이 같은 비율로 표시됨. `F` 키로 창 크기를 영상 비율에 맞게 조정하면
  레터박스가 제거됨(창 모드)
- **시청 중이던 영상**: 다른 폴더로 이동해도 트리 하단에 표시되고, 선택하면
  이전 재생 위치부터 재생됨
- **전체 화면**: 휠클릭 또는 `Enter`, `Esc`로 나옴. 창을 화면 전체로 넓히거나
  지금 창 크기 그대로 채우는 것 중에서 우클릭 메뉴로 선택하며, 고정 상태에서도
  사용 가능. 영상일 때는 썸네일 바가 자동으로 숨겨짐
- **폴더 검색** (`Ctrl+F` 또는 제목 표시줄 검색 아이콘으로 트리 ↔ 검색 화면
  전환, 폴더 우클릭 → **이 폴더에서 검색**도 가능): 폴더를 지정하면 그 폴더를
  인덱싱해 파일명을 즉시 찾음 — 부분일치 또는 `*`/`?` 와일드카드, 결과는
  폴더별로 묶여 표시되고 이름/날짜로 정렬 가능. 결과를 클릭하면 트리에서 해당
  위치로 이동(폴더가 맨 위에 고정)하거나 다른 앱으로 바로 끌어다 쓸 수 있고,
  최근 검색어를 기억함(`↑`/`↓`로 불러오고 개별 삭제 가능). `Ctrl+E`로 트리로
  복귀. **인덱싱 중에도 검색 가능** — 결과가 찾아지는 대로 올라옴
- **검색 인덱스 저장**: 한 번 인덱싱한 폴더는 다음 실행 때 다시 훑지 않고
  즉시 불러옴. 네트워크 드라이브(NAS)처럼 인덱싱이 오래 걸리는 곳에서 특히
  차이가 큼(60만 개 기준 약 6분 → 1초 남짓). 자동으로 다시 훑지는 않으므로
  상태줄에 인덱스가 언제 것인지 표시되고, 갱신은 새로고침 버튼으로
- **정렬**: 이름순/날짜순/유형순/크기순, 오름차순/내림차순 — 옵션("...") 메뉴 또는 폴더
  자신의 우클릭 메뉴에서 바꿀 수 있고, 후자는 그 폴더를 즉시 재정렬해서
  보여줌(다음 번 펼칠 때까지 기다릴 필요 없음)
- **아이콘 종류 2택**: 기본은 **윈도우 탐색기와 동일한 아이콘** —
  exe/바로가기 등은 탐색기처럼 그 파일 고유의 아이콘이 표시되고, 아이콘
  추출은 백그라운드에서 처리되어 네트워크 드라이브에서도 느려지지 않음.
  옵션 메뉴의 "아이콘 종류"에서 Material Icon Theme 기반 아이콘 셋
  ([THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md) 참고)으로 전환
  가능(재시작 불필요, 트리·검색 결과·북마크 패널 공통 적용); 드라이브 이름은
  굵게 표시

## 요구 사항

- Windows 10/11
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
  (소스에서 빌드/실행할 경우)

## 빌드 및 실행

```bash
git clone <this-repo-url>
cd Edgetree
dotnet run --project src/Edgetree
```

솔루션 전체 빌드:

```bash
dotnet build Edgetree.sln
```

## 단일 실행 파일로 배포하기

프레임워크 종속 (용량 작음, 대상 PC에 .NET 8 데스크톱 런타임 필요):

```bash
dotnet publish src/Edgetree -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
```

독립 실행형 (용량 큼, 대상 PC에 .NET 설치 불필요):

```bash
dotnet publish src/Edgetree -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```

`IncludeNativeLibrariesForSelfExtract` 옵션이 핵심입니다 — 이게 없으면 WPF의
네이티브 연동 DLL(`D3DCompiler_47_cor3.dll`, `wpfgfx_cor3.dll` 등)이 exe 안에
포함되지 않고 옆에 따로 풀려서, exe 파일 하나만 옮기면 실행이 안 됩니다.

어느 쪽이든 결과물은 `src/Edgetree/bin/Release/net8.0-windows/win-x64/publish/`
경로에 생성됩니다.

설치 버전은 세 번째 publish로 만듭니다 — 같은 self-contained 빌드에서
`PublishSingleFile`만 빼서 파일을 흩어진 채로 두는 것입니다. 그게 이 판의 존재
이유이기도 합니다. 단일 파일 self-contained는 실행할 때 자기를 메모리로 풀어내서,
.NET이 없는 PC의 작업 관리자에 350~400MB로 잡힙니다. 흩어진 파일은 디스크에서
정상적으로 매핑됩니다.

```bash
dotnet publish src/Edgetree -c Release -r win-x64 --self-contained true -o publish/folder
"$LOCALAPPDATA/Programs/Inno Setup 6/ISCC.exe" installer/Edgetree.iss
```

컴파일은 [Inno Setup 6](https://jrsoftware.org/isinfo.php)이 하고, 결과물은 나머지
둘과 같은 `releases/v<버전>/`에 떨어집니다. 스크립트가 버전을 exe에서 읽어 오므로
csproj만 올리면 됩니다.

- **폴더 내용 반영 개선**: 접어 뒀던 폴더를 다시 펼치면 그 사이의 변경이
  바로 반영되고, 외부에서 파일이 추가·삭제될 때의 화면 갱신이 더 안정적으로
- 다중 선택(Shift+클릭 범위 등)·우클릭 메뉴 조작 다듬기, 색상 설정이 변경
  즉시 저장되도록 개선
